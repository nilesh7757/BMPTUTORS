TutorMetric: Real Data on India's Private Tutors

We scraped and verified 107,673 tutor profiles from TeacherOn across all 36 Indian States and Union Territories, then cleaned them into two normalized tables so anyone can see fair pricing, subject overlaps, and which profiles are still active.

Why We Built This

Private tutoring in India is a messy, unorganized market. Parents have no idea what a fair hourly rate is — tutors quote anywhere from ₹200 to ₹3,500 for the same subject. TeacherOn shows profiles but doesn't tell you which ones are still active. We scraped 107,673 tutor profiles, verified which ones are live, and put fair pricing benchmarks in one place.

Primary Focus: Fairness, Transparency & Accessibility

Tools We Used

  • • Database: SQLite 3, Python 3.12, Pandas — 3NF normalized model (107k tutors, 403k offerings across 386 clean disciplines).
  • • Maps: Leaflet.js, GeoJSON — India map with state borders and density choropleth.
  • • Charts: Chart.js, Tailwind CSS — fee, tier, and subject breakdowns.
  • • Pricing ML: Ridge Regression with L2 regularization (R² = 9.8%, MAE = ₹370/hr on 72,001 rows) — baseline pricing estimator.
  • • Bio Generator: NLP + Gemini 2.5 Flash — writes parent and student profile bios.
Architecture: 3NF Normalized Relational Model

Who Uses It

  • • Parents & Students: Check fair hourly rates, find multi-subject bundles, and see verified local or online tutors.
  • • Private Tutors: See what others charge for your subject and city, and generate a professional bio.
  • • Researchers: Download the full normalized Excel file with 107k tutor records.
